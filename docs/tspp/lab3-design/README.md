# Результати проєктування програмної системи «StrongFit» (Лабораторна робота № 3)

### Обґрунтування архітектурного стилю та архітектурна діаграма
Для програмного продукту «StrongFit» було обрано та обґрунтовано Трирівневу (3-Tier) Клієнт-Серверну архітектуру. Вона забезпечує високий рівень безпеки завдяки ізоляції бази даних PostgreSQL за сервером бізнес-логіки Node.js, оптимальну масштабованість та швидкість розробки. На архітектурній діаграмі відображено взаємодію між графічним веб-інтерфейсом (Presentation Layer), серверною частиною REST API з бізнес-логікою (Business Logic Tier), реляційною БД PostgreSQL (Data Access Tier) та зовнішнім Geolocation API.

### ER-діаграма моделі даних проєкту
Спроєктована реляційна база даних складається з 6 основних сутностей: `users` (профілі користувачів), `categories` (види спорту), `user_categories` (проміжна таблиця зв'язку M:N), `posts` (дописи та програми тренувань), `messages` (приватний чат) та `complaints` (скарги для модерації). База даних забезпечує збереження персональних даних, зашифрованих паролів, геолокаційних координат та зв'язків між акторами системи відповідно до розробленої специфікації вимог.

### Каркас (Wireframe) та макет (Mockup) UX/UI
UX/UI-проєктування виконано з дотриманням принципів Mobile First та вимог стандарту ISO 9241. Спроєктований каркас (Wireframe) описує структурну взаємодію користувача (User Flow) через екрани авторизації, стрічки новин, пошуку партнерів на карті та приватного чату. Кольоровий макет (Mockup) реалізує візуальну концепцію бренду «StrongFit» у темно-фіолетових та неонових тонах (Deep Space & Purple Neon), забезпечуючи високу зручність використання та швидку навігацію.
